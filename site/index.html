TEST DATA GENERATOR · ภาษาไทย

ข้อมูลทดสอบภาษาไทย
ที่ผ่าน validation จริง

เลขบัตรประชาชนที่ check digit ถูกต้อง เบอร์มือถือ ชื่อ ที่อยู่ และวันที่ พ.ศ. ค้นหาแล้วกดคัดลอกไปวางในฟอร์มได้เลย

  • 15 ชนิดข้อมูล
  • สุ่มในเบราว์เซอร์ ไม่ส่งข้อมูลออก
  • มี library สำหรับ Automation

ไม่พบข้อมูลที่ค้นหา อยากให้มีเพิ่ม? เปิด issue บน GitHub

สร้างหลายรายการ

สร้างครั้งละหลายแถวสำหรับเตรียม test data ใส่ seed เดิมจะได้ข้อมูลชุดเดิมทุกครั้ง

ตรวจเลขบัตร

ใช้ได้ทั้งเลขบัตรประชาชนและเลขผู้เสียภาษี 13 หลัก จะพิมพ์ขีดหรือไม่ก็ได้

ใช้ในโค้ดเทส

ติดตั้งแล้วใช้กับ Playwright, Cypress หรือ Jest ได้ทันที

npm install thai-test-data

import { createThaiData } from "thai-test-data";

const td = createThaiData({ seed: 42 });
const user = td.person();

await page.fill("#citizenId", user.citizenId);
await page.fill("#phone", user.phone);

ข้อมูลทั้งหมดสุ่มขึ้นในเบราว์เซอร์ของคุณ ไม่มีการส่งหรือเก็บไว้ที่ใด ใช้เพื่อทดสอบระบบเท่านั้น เลขที่สุ่มอาจบังเอิญตรงกับบุคคลจริงได้ ห้ามนำไปใช้สมัครบริการจริงหรือแอบอ้างตัวตน
