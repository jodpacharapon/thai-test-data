Docs

ติดตั้ง library แล้วเรียกใช้ใน test script ได้เลย ได้ข้อมูลแบบเดียวกับในหน้า Generator รองรับ Playwright, Cypress, Jest และ Vitest

Installation

npm install thai-test-data

Usage with Playwright

ใส่ seed เพื่อให้ได้ข้อมูลชุดเดิมทุกครั้งที่รัน เวลาเทสพังจะ debug ได้ง่าย

import { test, expect } from "@playwright/test";
import { createThaiData } from "thai-test-data";

const td = createThaiData({ seed: 42 });

test("สมัครสมาชิกด้วยข้อมูลที่ถูกต้อง", async ({ page }) => {
  const user = td.person();
  await page.goto("/register");
  await page.fill("#citizenId", user.citizenId);
  await page.fill("#phone", user.phone);
  await page.fill("#address", user.address.fullAddress);
  await page.click("button[type=submit]");
  await expect(page.getByText("สมัครสำเร็จ")).toBeVisible();
});

test("ปฏิเสธเลขบัตรที่ผิด", async ({ page }) => {
  await page.goto("/register");
  await page.fill("#citizenId", td.invalidCitizenId());
  await page.click("button[type=submit]");
  await expect(page.getByText("เลขบัตรประชาชนไม่ถูกต้อง")).toBeVisible();
});

API Reference

td.citizenId(firstDigit?)เลขบัตรประชาชนที่ถูกต้อง กำหนดหลักแรก 1-8 ได้
td.invalidCitizenId(kind?)เลขบัตรที่ผิด สำหรับ negative test: "checksum" | "short" | "long" | "letters"
td.juristicId()เลขผู้เสียภาษีนิติบุคคล
td.invalidJuristicId(kind?)เลขนิติบุคคลที่ผิด ใช้ kind แบบเดียวกัน
td.phone(prefixes?)เบอร์มือถือ 10 หลัก จำกัดเลขขึ้นต้นได้ เช่น ["08"]
td.invalidPhone(kind?)เบอร์ที่ผิด: "prefix" | "short" | "long" | "letters"
td.name("male" | "female")ชื่อ-นามสกุลไทยและอังกฤษ
td.address()ที่อยู่ที่จังหวัด อำเภอ ตำบล รหัสไปรษณีย์ตรงกัน
td.birthDate(min, max)วันเกิดตามช่วงอายุ
td.person()ข้อมูลบุคคลครบชุด
td.many(n, fn)สร้างทีละหลายรายการ
isValidThaiId(value)ตรวจเลข 13 หลัก

ข้อมูลทั้งหมดสุ่มในเบราว์เซอร์ของคุณ ไม่มีการส่งหรือเก็บไว้ที่ใด ใช้เพื่อทดสอบระบบเท่านั้น เลขที่สุ่มอาจบังเอิญตรงกับบุคคลจริง ห้ามนำไปใช้สมัครบริการจริงหรือแอบอ้างตัวตน
